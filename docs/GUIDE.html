BuildPact Guide

Le pacte on-chain des builders Solana — répartition des parts entre co-fondateurs, formalisée avant qu'il y ait de l'argent à partager. Cette page réunit le mode d'emploi, la feuille de route et l'état du projet en un seul endroit consultable dans le navigateur.

The on-chain pact for Solana builders — founder equity split, formalized before there's any money to share. This page brings together the user guide, the roadmap, and the project's current state in one browsable place.

01Le produitThe product

Un porteur de projet (« founder ») crée un Project on-chain avec des membres et leurs parts en points de base. Les devs postulent, s'approuvent mutuellement, le founder finalise — la répartition devient immuable. Les backers financent via un vault PDA en escrow ; la distribution est automatique : 2 % protocole, 98 % aux membres selon leurs parts.

A project owner (the "founder") creates an on-chain Project with members and their basis-point shares. Devs apply, mutually approve each other, the founder finalizes — the split becomes immutable. Backers fund through an escrow vault PDA; distribution is automatic: 2% protocol fee, 98% to members per their share.

02Mode d'emploiUser guide

Créer un pact

Create a pact

  1. Connecter un wallet Solana (devnet) depuis n'importe quelle page.
  2. Connect a Solana wallet (devnet) from any page.
  3. Depuis le dashboard, lancer « Créer un pact » : titre, description, rôles et parts (total 10 000 bps).
  4. From the dashboard, start "Create a pact": title, description, roles and shares (total 10,000 bps).
  5. Inviter des membres ou laisser le pact ouvert au marketplace pour candidatures.
  6. Invite members, or leave the pact open on the marketplace for applications.
  7. Chaque membre approuve — une fois tous approuvés, le founder finalise on-chain.
  8. Each member approves — once everyone has approved, the founder finalizes on-chain.

Profil — dashboard en grille libre

Profile — free-grid dashboard

La page #/profil est une grille entièrement libre : chaque bloc (formulaire de profil, pacts & gains, contact, chat, progression, quêtes, wallet) se déplace par la poignée ⠿⠿ en haut de chaque carte, et se redimensionne par le coin bas-droit. La disposition est sauvegardée automatiquement par wallet — personne ne repart de zéro à la prochaine visite.

The #/profile page is a fully free grid: every block (profile form, pacts & earnings, contact, chat, progression, quests, wallet) is dragged by the ⠿⠿ handle at the top of each card, and resized from the bottom-right corner. The layout is saved automatically per wallet — nobody starts from scratch on their next visit.

Financer et distribuer

Fund and distribute

Sur la fiche d'un pact finalisé : le bouton vert (couleur réservée aux mouvements de SOL dans toute l'app) déclenche fund / distribute / claim. La page Trésorerie liste chaque mouvement avec son tx_sig, cliquable vers l'explorateur — la chaîne reste la seule source de vérité.

On a finalized pact's page: the green button (a color reserved app-wide for SOL movements) triggers fund / distribute / claim. The Treasury page lists every movement with its tx_sig, clickable to the explorer — the chain remains the only source of truth.

RÉSOLURESOLVED

Incident de synchronisation Noah ↔ GitHub

Noah ↔ GitHub sync incident

Noah n'avait poussé sur GitHub qu'une seule fois depuis la création du dépôt — 143 commits restaient bloqués localement. Résolu en recréant un dépôt GitHub propre et en le reconnectant à Noah et à Vercel. Nouvelle règle du projet : jamais plus de 5 fichiers modifiés par passe de synchronisation.

Noah had only pushed to GitHub once, right when the repo was created — 143 commits stayed stuck locally. Fixed by recreating a clean GitHub repo and reconnecting it to Noah and Vercel. New project rule: never more than 5 files changed per sync pass.

À SAVOIRGOOD TO KNOW

Déploiement auto parfois bloqué (plan Hobby)

Auto-deploy sometimes blocked (Hobby plan)

Un déploiement déclenché par push GitHub peut être refusé si l'auteur du commit n'est pas reconnu comme collaborateur Vercel. Solution : déployer en CLI — git pull && vercel --prod — un déploiement CLI n'est jamais concerné par cette restriction.

A deployment triggered by a GitHub push can be refused if the commit author isn't recognized as a Vercel collaborator. Fix: deploy via CLI — git pull && vercel --prod — a CLI deploy is never subject to this restriction.

NOVA

Nouvelle palette vive + chantier UI "fun"

New vivid palette + "fun" UI effort

Palette Nova (magenta électrique + lime) ajoutée au sélecteur. Premier pas d'un chantier plus large déjà validé : vrai thème clair, micro-animations, cartes en glassmorphism, personnalisation du profil (bannière, cadre d'avatar par rang), et un passage WCAG AA sur les contrastes.

The Nova palette (electric magenta + lime) was added to the selector. First step of a larger, already-approved effort: a real light theme, micro-animations, glassmorphism cards, profile personalization (banner, rank-based avatar frame), and a WCAG AA contrast pass.

CORRIGÉFIXED

Scroll infini sur le profil

Infinite scroll on profile

Un bug de breakpoint hérité laissait des blocs de la grille libre poussés à des dizaines de milliers de pixels plus bas, et d'autres écrasés sur 1 pixel de large. Les deux sont désormais détectés et corrigés automatiquement au chargement.

A legacy breakpoint bug left free-grid blocks pushed tens of thousands of pixels down, and others crushed to 1 pixel wide. Both are now detected and fixed automatically on load.
