01 · Architecture

On-chain pour l’accord, off-chain pour l’expérience

On-chain

Projet, membres, approvals, statut, vault, funding et distribution. RPC : Helius devnet prioritaire, fallback Ankr puis RPC Solana.

Off-chain

Supabase pour signMessage, profil et chat Realtime ; GitHub/Discord restent l’espace de travail.

Déploiement

Frontend React + Vite + TypeScript + Tailwind sur Vercel. Mainnet post-hackathon uniquement.

02 · Programmes & données

IDL et contraintes canoniques

Instructions

initialize_config, create_project, add_member, remove_member, approve, finalize, fund, distribute, close_project.

PDAs

Project : ["project", creator, project_id]. Vault : ["vault", project]. Config dans l’IDL : ["config", authority]. Bump stocké.

Comptes

Config : authority, actif/pause, fee bps, version. Project : creator, project_id ≤ 32 caractères, titre, description, members, statut Open/Finalized, protocol_wallet.

pub struct Member {
  pub wallet: Pubkey,
  pub role: String,
  pub share_bps: u16,
  pub approved: bool,
}
// invariant : somme exacte = 10_000 bps

Règles critiques : finalize founder-only ; tous les membres approuvent ; après finalize les parts sont verrouillées ; distribute exige remaining_accounts dans l’ordre exact de project.members ; arithmétique checked.

03 · Sécurité

Known issues Seed Vault / MWA

VersionedTransaction v0 Résolu

La sérialisation legacy créait une signature manquante. Corrigé dans le flux réel.

ComputeBudget Résolu

Limite et prix injectés avant signature pour éviter l’altération Phantom.

RPC / identité Résolu

Helius dédié contre 429 ; window.location.origin pour l’identité dynamique.

Seed Vault mobile Bloquant démo

Seeker : Backpack mobile en devnet confirmé fiable ; Phantom et Solflare mobiles restent en boucle de signature / estimation de frais. Desktop Brave/Chrome : trois wallets fiables.

Nonce durable Abandonné

Tests sandbox non concluants ; avertissements anti-phishing bloquants chez Backpack et Phantom. Ne pas porter en V1.

Domaine non reconnu À valider

Avertissement normal du wallet et expiration du blockhash ; aucun contournement durable retenu.

Démo : desktop recommandé. Si mobile obligatoire : Backpack basculé en Devnet. Ne pas utiliser Phantom/Solflare mobile devant les juges.

CI/CD Détail à valider

Pipeline recommandé : lint + typecheck, tests Anchor, build Vite, scan dépendances, déploiement Vercel avec alias stable. La configuration CI exacte n’est pas fournie dans les sources.

Audit avant mainnet

Vérifier signer et relations, seeds PDA, plafonds de chaînes, somme exacte des shares, ordre des membres, frais, fermeture du vault, replay et autorité Config. Mainnet après audit : non réalisé/documenté.
