Ce que dit la documentation Noah
  • La connexion GitHub peut se démarrer depuis le projet ou depuis Settings → Integration.
  • Pour un projet non encore connecté, Noah propose la création d’un dépôt privé; ensuite le dialogue affiche le dépôt et la branche active. Le changement de branche est documenté.
  • La page ne décrit pas comment remplacer le dépôt d’un projet déjà relié.
  • Disconnect, depuis Settings → Integration → GitHub, retire l’accès Noah mais ne supprime pas les dépôts. La portée sur les autres projets n’est pas précisée.
  • Le texte d’avertissement de renommage de dépôt mentionne « Lovable », incohérence de rédaction; ne pas en déduire de garantie Noah particulière.
