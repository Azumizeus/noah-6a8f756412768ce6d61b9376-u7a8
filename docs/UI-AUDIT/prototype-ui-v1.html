Comment ça marche

01

Créer

Décris ton projet, tes rôles et ta part. Choisis ce que tu cherches : devs, investisseurs, ou les deux.

02

Rejoindre

Les membres postulent avec leur wallet, leur rôle et leur part négociée. Chacun approuve on-chain.

03

Finaliser

Une fois toutes les approbations réunies et les parts à 100%, le founder verrouille le pact on-chain.

04

Financer

Les backers envoient des fonds dans le vault du projet — escrow PDA, entièrement vérifiable.

05

Distribuer

2% protocole, 98% réparti automatiquement entre les membres selon leurs parts. Aucun virement manuel.

Pourquoi BuildPact

Solo founder

Un fondateur peut cadrer l'idée, publier les besoins, intégrer les membres et verrouiller l'accord sans coordination manuelle des paiements.

La confiance, c'est du code

Rôles, parts, approbation, escrow et distribution deviennent vérifiables on-chain — plus besoin de contrats informels.

Où travaillent les devs ?

Sur GitHub et Discord. BuildPact ne les remplace pas : il apporte la couche confiance + paiement qui leur manque.
