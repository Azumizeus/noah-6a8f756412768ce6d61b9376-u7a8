Le concept
BuildPact est le hub de confiance pour les builders Solana : publier une idée, préciser les rôles recherchés et la répartition %, recevoir des candidatures, puis inscrire l'accord on-chain lorsque toutes les parties l'ont approuvé. Les revenus sont distribués automatiquement et des backers peuvent financer via escrow.

Positionnement : GitHub et Discord restent l'espace de travail. BuildPact est la couche confiance + paiement — accord on-chain, escrow et distribution. V1 = parts garanties ; V2 = jalons, réputation on-chain, remplacement de membres.
